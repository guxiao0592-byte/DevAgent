# 简易计算器应用需求文档

## 概述
构建一个基于 Python 的计算器应用，支持基本算术运算。

## 功能需求

1. **基本运算**：支持加法 (+)、减法 (-)、乘法 (*)、除法 (/)
2. **输入处理**：接受字符串格式的数学表达式（例如 "3 + 4 * 2"）
3. **运算符优先级**：遵循标准数学优先级（乘除优先于加减），支持括号
4. **错误处理**：对除零和无效输入返回清晰的错误信息
5. **结果展示**：计算结果保留 2 位小数

## 非功能需求
- 使用 Python 3.10+ 编写
- 包含完整的 docstring 文档注释
- 包含完整的类型标注（type hints）
- 优雅处理边界情况

## 验收标准
- 3 + 4 = 7.00
- 10 - 5 = 5.00
- 6 * 7 = 42.00
- 15 / 3 = 5.00
- 10 / 0 返回清晰错误信息
- "abc + 5" 这类非法输入返回清晰错误信息
- 3 + 4 * 2 = 11.00（优先级正确）
- (3 + 4) * 2 = 14.00（括号支持）
