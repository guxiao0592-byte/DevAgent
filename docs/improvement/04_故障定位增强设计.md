## 1. 概述

### 1.1 问题陈述

DevAgent V1 的 DebugAgent 仅依赖 LLM 的静态文本推理来定位 bug，存在明显不足：
- 没有利用运行时信息（哪个测试失败了、实际值 vs 期望值）
- 没有利用覆盖信息（哪些代码被执行了、哪些没有）
- 在大项目中难以从海量代码中精准定位

### 1.2 设计目标

- 将故障定位粒度从"整个文件"提升到"具体函数/行"
- 融合多种定位信号：SBFL（频谱）、AST 静态分析、LLM 推理
- Top-1 定位准确率达到 > 60%

## 2. 业界参考

| 系统 | 定位方法 | 粒度 | 准确率(SWE-bench) |
|------|---------|------|-------------------|
| AutoCodeRover | SBFL + LLM | 函数级 | ~28% resolved |
| Agentless | LLM 直接定位 | 文件+行号 | ~30% resolved |
| SWE-Fixer | 静态 + 动态 + LLM | 行级 | ~24% resolved |
| SWE-agent | LLM + grep 探索 | 文件级 | ~18% resolved |

## 3. 三层混合定位架构

```
Layer 1: 动态频谱分析 (SBFL)
  └── 利用 coverage.py 收集执行轨迹 → 计算每条语句的怀疑度

Layer 2: 静态结构分析
  └── AST 调用链分析 → 类型推导 → 边界条件检查

Layer 3: LLM 推理定位
  └── 融合前两层信号 + 错误信息 → 精确判定 bug 位置和原因
```

### 3.1 Layer 1: 频谱故障定位 (SBFL)

#### 原理

SBFL 利用"被失败测试执行过多次的代码更有可能是 bug"和"被通过测试执行过的代码不太可能是 bug"的原则，为每条语句计算怀疑度分数。

#### 实现

```python
class SBFLocalizer:
    """基于频谱的故障定位器"""

    class Statement:
        file: str
        line: int
        function: str
        suspiciousness: float = 0.0

    def localize(self, repo_path: str, test_path: str) -> list[Statement]:
        """运行所有测试，收集执行轨迹，计算怀疑度"""
        # Step 1: 收集执行轨迹
        tracer = CoverageTracer(repo_path)

        passed_traces = []   # 通过测试的执行轨迹
        failed_traces = []   # 失败测试的执行轨迹

        for test_file in self._discover_tests(test_path):
            for test_func in self._discover_test_funcs(test_file):
                trace = tracer.run_test(test_file, test_func)

                if trace.passed:
                    passed_traces.append(trace)
                else:
                    failed_traces.append(trace)

        # Step 2: 计算每条语句的频谱统计
        # a_ef: 失败测试执行过该语句的次数
        # a_ep: 通过测试执行过该语句的次数
        # a_nf: 失败测试未执行该语句的次数
        # a_np: 通过测试未执行该语句的次数

        total_failed = len(failed_traces)
        total_passed = len(passed_traces)

        statements = set()
        for trace in failed_traces + passed_traces:
            statements.update(trace.stmts)

        for stmt in statements:
            a_ef = sum(1 for t in failed_traces if stmt in t.stmts)
            a_ep = sum(1 for t in passed_traces if stmt in t.stmts)
            a_nf = total_failed - a_ef
            a_np = total_passed - a_ep

            # Ochiai 公式（最常见的 SBFL 指标）
            denom = ((a_ef + a_nf) * (a_ef + a_ep)) ** 0.5
            stmt.suspiciousness = a_ef / denom if denom > 0 else 0.0

        # Step 3: 按怀疑度排序
        ranked = sorted(statements, key=lambda s: s.suspiciousness, reverse=True)
        return ranked
```

#### CoverageTracer 实现

```python
class CoverageTracer:
    """基于 sys.settrace 的轻量级执行轨迹收集器"""

    def run_test(self, test_file: str, test_func: str) -> TraceResult:
        """运行单个测试并收集执行轨迹"""
        stmts = set()
        error_info = None
        passed = True

        def trace_callback(frame, event, arg):
            if event == 'line':
                filename = frame.f_code.co_filename
                lineno = frame.f_lineno
                funcname = frame.f_code.co_name
                if self._is_project_file(filename):
                    stmts.add(Statement(
                        file=os.path.relpath(filename),
                        line=lineno,
                        function=funcname
                    ))
            return trace_callback

        sys.settrace(trace_callback)
        try:
            result = subprocess.run(
                ["python", "-m", "pytest", f"{test_file}::{test_func}", "-xvs"],
                capture_output=True, timeout=30
            )
            passed = result.returncode == 0
            if not passed:
                error_info = self._parse_error(result.stdout + result.stderr)
        finally:
            sys.settrace(None)

        return TraceResult(stmts=stmts, passed=passed, error_info=error_info)

    def _is_project_file(self, filename: str) -> bool:
        """判断是否是项目源代码文件（排除标准库和第三方库）"""
        return (
            filename.startswith(self.project_root) and
            not '/venv/' in filename and
            not '/site-packages/' in filename and
            filename.endswith('.py')
        )
```

### 3.2 Layer 2: 静态结构分析

```python
class StaticAnalyzer:
    """基于 AST 的静态缺陷模式检查"""

    def analyze(self, file_path: str) -> list[Issue]:
        issues = []

        tree = ast.parse(Path(file_path).read_text())

        # Check 1: None 检查缺失
        issues.extend(self._check_null_missing(tree, file_path))

        # Check 2: 边界条件缺失
        issues.extend(self._check_boundary_missing(tree, file_path))

        # Check 3: 异常处理缺失
        issues.extend(self._check_exception_missing(tree, file_path))

        # Check 4: 类型不匹配（追踪类型注解）
        issues.extend(self._check_type_mismatch(tree, file_path))

        # Check 5: 调用链中的错误传播
        issues.extend(self._check_error_propagation(tree, file_path))

        return issues

    def _check_null_missing(self, tree, file_path) -> list[Issue]:
        """检测可能返回 None 但调用方未处理的场景"""
        issues = []
        # 收集所有 return None 的函数
        nullable_funcs = set()
        for node in ast.walk(tree):
            if isinstance(node, ast.FunctionDef):
                for child in ast.walk(node):
                    if isinstance(child, ast.Return) and child.value is None:
                        nullable_funcs.add(node.name)

        # 查找调用 nullable 函数但未做 None 检查的代码
        for node in ast.walk(tree):
            if isinstance(node, ast.Call):
                if self._get_func_name(node) in nullable_funcs:
                    if not self._has_null_check(node):
                        issues.append(Issue(
                            file=file_path,
                            line=node.lineno,
                            message=f"Return value of '{self._get_func_name(node)}' (returns None) not checked",
                            confidence=0.6
                        ))
        return issues

    def _check_boundary_missing(self, tree, file_path) -> list[Issue]:
        """检测循环、数组访问、除法的边界条件"""
        issues = []
        for node in ast.walk(tree):
            # 数组索引访问没有边界检查
            if isinstance(node, ast.Subscript):
                if not self._has_boundary_check(node, tree):
                    issues.append(Issue(
                        file=file_path, line=node.lineno,
                        message="Index access without boundary check",
                        confidence=0.4
                    ))

            # 除法没有零检查
            if isinstance(node, ast.BinOp) and isinstance(node.op, ast.Div):
                if not self._has_zero_check(node, tree):
                    issues.append(Issue(
                        file=file_path, line=node.lineno,
                        message="Division without zero check",
                        confidence=0.5
                    ))
        return issues

    def extract_call_graph(self, files: list[str]) -> dict:
        """提取调用图：{caller_function: [callee_functions]}"""
        graph = {}
        for file_path in files:
            tree = ast.parse(Path(file_path).read_text())
            for node in ast.walk(tree):
                if isinstance(node, ast.FunctionDef):
                    caller = f"{file_path}:{node.name}"
                    callees = []
                    for child in ast.walk(node):
                        if isinstance(child, ast.Call):
                            callee = self._get_func_name(child)
                            if callee:
                                callees.append(callee)
                    graph[caller] = callees
        return graph
```

### 3.3 Layer 3: LLM 融合推理

```python
class LLMFaultLocalizer:
    """融合 SBFL 信号和静态分析结果，用 LLM 做最终精确判定"""

    PROMPT = """You are a fault localization expert. Given the following information, identify the exact bug location and explain the root cause.

## Error Information
- Test: {test_name}
- Error message: {error_message}
- Assertion: expected={expected}, actual={actual}

## SBFL Results (code ranked by suspiciousness)
{sbfl_ranked}

## Static Analysis Warnings
{static_warnings}

## Focus Code
{code_snippets}

## Instructions
1. Identify the EXACT bug location: file, function, line(s)
2. Explain WHY this is the bug (what went wrong)
3. Propose the minimal code change to fix it
4. Confidence level: high / medium / low

Output JSON:
{{
  "bug_location": {{
    "file": "...",
    "function": "...",
    "line": 42,
    "suspected_code": "..."
  }},
  "root_cause": "...",
  "fix": "...",
  "confidence": "high"
}}"""

    def localize(self, error_info: dict, sbfl_results: list, static_issues: list, code_files: dict) -> dict:
        # 融合 SBFL Top-10 + 静态 Top-10 → 选择交集 Top-5 给 LLM
        sbfl_files = {s.file for s in sbfl_results[:20]}
        static_files = {i.file for i in static_issues}

        # 优先级：SBFL ∩ 静态 > SBFL only > 静态 only
        overlap = sbfl_files & static_files
        priority_files = list(overlap)[:5] + list(sbfl_files - overlap)[:3]

        # 构建 LLM 输入
        code_snippets = {}
        for file_path in priority_files:
            content = self._read_file(file_path)
            # 只取怀疑度最高的函数所在代码块
            suspect_functions = {
                s.function for s in sbfl_results[:10] if s.file == file_path
            }
            for func in suspect_functions:
                snippet = self._extract_function_body(content, func)
                if snippet:
                    code_snippets[f"{file_path}:{func}"] = snippet

        result = self.llm.chat_structured(
            messages=[{"role": "user", "content": self.PROMPT.format(
                test_name=error_info.get("test_name"),
                error_message=error_info.get("error_message"),
                expected=error_info.get("expected", "?"),
                actual=error_info.get("actual", "?"),
                sbfl_ranked=self._format_sbfl_top(sbfl_results[:10]),
                static_warnings=self._format_static(static_issues[:10]),
                code_snippets=json.dumps(code_snippets, indent=2)
            )}]
        )
        return result
```

## 4. 端到端故障定位流程

```python
class FaultLocalizationPipeline:
    """综合故障定位流水线"""

    def __init__(self):
        self.sbfl = SBFLocalizer()
        self.static = StaticAnalyzer()
        self.llm_loc = LLMFaultLocalizer()

    async def localize(self, state: AgentLoopState) -> FaultReport:
        # Step 1: 收集失败测试信息
        error_info = await self._collect_error_info(state)

        # Step 2: 并行运行 SBFL 和静态分析
        sbfl_task = asyncio.create_task(self._run_sbfl(state))
        static_task = asyncio.create_task(self._run_static(state))

        sbfl_results = await sbfl_task
        static_issues = await static_task

        # Step 3: LLM 融合推理
        if sbfl_results or static_issues:
            llm_result = await self.llm_loc.localize(
                error_info, sbfl_results, static_issues, self._code_files(state)
            )
        else:
            # Fallback: 纯 LLM 探索式定位
            llm_result = await self._exploratory_localize(state, error_info)

        return FaultReport(
            sbfl=sbfl_results,
            static=static_issues,
            llm=llm_result,
            combined=self._combine_results(sbfl_results, static_issues, llm_result)
        )
```

## 6. 性能考量

| 场景 | SBFL 耗时 | 静态分析耗时 | LLM 推理耗时 | 总计 |
|------|----------|------------|------------|------|
| 小项目 (<1K行, 10测试) | ~5s | ~1s | ~3s | ~9s |
| 中项目 (10K行, 50测试) | ~30s | ~3s | ~5s | ~38s |
| 大项目 (100K行, 200测试) | ~3min | ~10s | ~8s | ~3.5min |

优化策略：
- SBFL 仅运行与失败测试相关的测试文件
- 静态分析缓存 AST 解析结果
- 大项目中可跳过 SBFL，仅用静态 + LLM
