## 1. 现状分析

### 1.1 已有基础设施（可复用）

DevAgent V2 已经具备了一套**部分实现但未完全集成**的实时交互基础设施：

```
┌─────────────────────────────────────────────────────────────────┐
│                    已有组件（未完全打通）                         │
│                                                                 │
│  EventBus ─────────→ StreamingServer ──→ WebSocket (/realtime) │
│  (事件发布订阅)       (SSE队列推送)          (仅单向输出，无输入)  │
│                                                                 │
│  HumanInTheLoop ────→ Future-based approval                    │
│  (审批门定义)          (未接入 core.py 执行循环)                  │
│                                                                 │
│  StateGraph.interrupt ─→ Checkpoint + Resume                   │
│  (中断/恢复机制)         (未接入用户交互通道)                     │
│                                                                 │
│  TaskHistoryManager ──→ Dashboard HTML                          │
│  (历史管理+趋势)         (仅轮询，无实时推送)                     │
│                                                                 │
│  ConsoleEmitter ────→ CLI 被动输出                              │
│  (事件→控制台)         (无交互式输入)                             │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 关键缺陷详细分析

#### 缺陷 1：HumanInTheLoop 完全孤立（最严重）

```python
# core.py:165 — 初始化了但从未使用
self.hitl = HumanInTheLoop()

# core.py:318 — _execute_single_step 中没有任何审批检查
async def _execute_single_step(self, state, action, tools, context_mgr):
    # ❌ 没有: point_id = self.hitl.needs_approval(action, state)
    # ❌ 没有: await self.hitl.request_approval(point_id, details)
    ...
```

**影响**: 即使用了 `--task agentic`，Agent 在遇到以下情况时，用户完全无法干预：
- 即将执行危险 Shell 命令（`rm -rf`、`git push --force`）
- 尝试大规模文件编辑（>50行变更）
- Agent 接近最大迭代次数即将失败

#### 缺陷 2：WebSocket 仅是单向模拟

```python
# api/app.py:257 — WebSocket 端点，但内容是假的模拟！
@app.websocket("/api/v1/tasks/{task_id}/stream")
async def task_stream(websocket, task_id):
    phases = ["initializing", "analyzing", "generating", ...]  # 硬编码
    for phase in phases:
        await asyncio.sleep(0.5)       # 虚假延迟
        await websocket.send_json({...})  # 假数据
```

**影响**: WebSocket 连接虽然建立了，但流的不是真实任务数据，而是一个模拟阶段进度。

真正的流式推送在 `observability.py:595` 的 `/api/v1/tasks/{task_id}/stream/realtime` 端点，但它：
- 没有在 `DevAgentCore` 启动时被注册
- 没有对应的 `app.py` 路由

#### 缺陷 3：Agent 无法向用户提问

V2 的 19 种工具中没有 `ask_user` 工具。当 Agent 遇到以下情况时只能猜测或失败：
- 需求描述模糊需要澄清
- 修复方案有多种选择需要用户决策
- 定位到多个可能的缺陷源需要确认

#### 缺陷 4：CLI 完全无交互能力

```python
# cli/main.py:226 — agentic 模式是同步阻塞的
state = core.execute(task_description=task_desc, workspace=workspace)
# ❌ 执行期间用户什么都做不了，只能等结束或 Ctrl+C
```

#### 缺陷 5：Dashboard 使用轮询而非推送

```javascript
// observability.py:537 — 每5秒轮询一次
loadTasks();
setInterval(loadTasks, 5000);
```

这导致至少 5 秒的延迟，且增加不必要的后端负载。

### 1.3 缺陷影响矩阵

| 缺陷 | 用户体验影响 | 安全影响 | 效率影响 |
|------|------------|---------|---------|
| HITL未集成 | 无法审批危险操作 | **高** — 危险命令无阻断 | 中 |
| WS单向模拟 | 看不到真实进度 | 低 | 高 — 用户焦虑等待 |
| 无ask_user | 需求澄清靠猜 | 中 — 错误决策 | **高** — 大量返工 |
| CLI阻塞 | 只能Ctrl+C | 低 | 中 |
| Dashboard轮询 | 信息滞后5s+ | 低 | 低 |

## 2. 改进目标

### 2.1 核心目标

实现 **DevAgent 执行过程中的双向实时交互**，让用户能够：

1. **实时观察**: 看到 Agent 每步的思考（THOUGHT）、动作（ACTION）、结果（OBSERVATION）
2. **主动干预**: 在关键时刻暂停、引导、或终止 Agent 的执行
3. **被动响应**: 当 Agent 需要用户决策时，及时收到通知并做出选择
4. **渐进预览**: 在代码生成/修复过程中查看中间产物
5. **会话上下文**: 交互历史在重连后不丢失

### 2.2 非功能性目标

- **延迟**: 事件从生成到前端展示 < 200ms
- **可靠性**: 连接断开后自动重连，状态不丢失（基于 checkpoint 恢复）
- **扩展性**: 单个任务支持多客户端同时观察（1个主控 + N个观察者）
- **兼容性**: CLI / Web Dashboard / IDE 插件三种终端均支持交互

### 3.2 核心设计原则

1. **最小侵入**: 对现有 `DevAgentCore` 的修改通过 hook 机制实现，不改变主循环结构
2. **异步非阻塞**: 所有交互操作通过 async/await + Queue 实现，不影响 Agent 执行效率
3. **状态可恢复**: 所有交互状态基于 checkpoint 机制，客户端断线重连后完整恢复
4. **协议统一**: CLI/Web/IDE 三种客户端共享同一套消息协议
5. **渐进增强**: 每阶段产出可独立部署，不依赖后续阶段

## 4. 详细模块设计

### 4.1 InteractionController — 交互控制器（核心新增模块）

**文件**: `devagent/agentic/interaction.py`

```python
"""
InteractionController — bridges the Agentic Loop with user interaction channels.

Architecture:
  ┌─────────────────────────────────────────────────────────┐
  │                  InteractionController                  │
  │                                                         │
  │  pre_action_hooks  →  [ApprovalGate, ProgressNotifier] │
  │  post_action_hooks →  [StatePublisher, ArtifactNotifier]│
  │  command_handler   →  [Pause/Resume/Abort/Skip/Redirect]│
  │  dialogue_manager  →  [AskUser, Clarify, Decide]        │
  └─────────────────────────────────────────────────────────┘
"""

import asyncio
import enum
import time
from dataclasses import dataclass, field
from typing import Optional, Callable, Awaitable
from datetime import datetime


# ============================================================================
# Data Types
# ============================================================================

class CommandType(str, enum.Enum):
    """Commands that the user can send during execution."""
    PAUSE = "pause"           # Pause after current step
    RESUME = "resume"         # Resume from pause
    ABORT = "abort"           # Gracefully abort, save checkpoint
    SKIP = "skip"             # Skip current step, continue to next
    RETRY = "retry"           # Retry current step with hint
    REDIRECT = "redirect"     # Change task focus/priority
    INJECT_CONTEXT = "inject" # Inject additional context/constraint
    FORCE_TERMINATE = "kill"  # Hard stop, no checkpoint


class ApprovalType(str, enum.Enum):
    """Types of actions requiring user approval."""
    DESTRUCTIVE_SHELL = "destructive_shell"   # rm -rf, git push --force
    LARGE_EDIT = "large_edit"                 # >50 lines changed
    UNCERTAIN_FIX = "uncertain_fix"           # Low confidence fix
    UNVERIFIED_EDIT = "unverified_edit"       # Editing unread file
    EXTERNAL_API_CALL = "external_api"        # Call to external service
    FILE_DELETE = "file_delete"              # Deleting files
    GIT_OPERATION = "git_operation"          # Non-readonly git operations
    CONFIG_CHANGE = "config_change"          # Modifying config files
    NETWORK_ACCESS = "network_access"         # Outbound network requests


@dataclass
class ApprovalRequest:
    """A single approval request sent to the user."""
    id: str
    type: ApprovalType
    description: str
    details: dict = field(default_factory=dict)
    options: list[str] = field(default_factory=list)  # ["approve", "deny", "modify"]
    timeout_seconds: int = 120
    created_at: str = field(default_factory=lambda: datetime.now().isoformat())
    resolved: bool = False
    resolution: Optional[str] = None
    user_note: str = ""


@dataclass
class UserCommand:
    """A command from the user injected into the execution loop."""
    type: CommandType
    data: dict = field(default_factory=dict)
    timestamp: str = field(default_factory=lambda: datetime.now().isoformat())
    client_id: str = ""


@dataclass
class ProgressSnapshot:
    """Complete progress snapshot sent to clients."""
    task_id: str
    status: str
    iteration: int
    max_iterations: int
    phase: str                       # exploration / editing / verification
    current_action: Optional[dict]   # Current step's THOUGHT/ACTION
    recent_history: list[dict]       # Last 5 action-observation pairs
    modified_files: list[str]
    test_results: Optional[dict]
    pending_approval: Optional[dict]  # If waiting for user
    artifacts: dict                   # {phase: [file_paths]}
    progress_pct: float               # 0.0 - 1.0
    timestamp: str


# ============================================================================
# InteractionController
# ============================================================================

class InteractionController:
    """Central controller for all user-agent interactions during execution."""

    def __init__(self, event_bus, streaming_server, hitl_manager,
                 session_manager, enable_approval: bool = True,
                 enable_dialogue: bool = True):
        self.event_bus = event_bus
        self.streaming = streaming_server
        self.hitl = hitl_manager
        self.session_mgr = session_manager

        # Queues
        self._command_queue: asyncio.Queue[UserCommand] = asyncio.Queue()
        self._approval_queue: asyncio.Queue[ApprovalRequest] = asyncio.Queue()
        self._pending_approval: Optional[ApprovalRequest] = None

        # Config
        self.enable_approval = enable_approval
        self.enable_dialogue = enable_dialogue
        self.auto_approve_policy: dict[ApprovalType, bool] = {}

        # Hooks
        self.pre_action_hooks: list[Callable[..., Awaitable]] = [
            self._check_approval_gate,
            self._publish_pre_action_state,
        ]
        self.post_action_hooks: list[Callable[..., Awaitable]] = [
            self._publish_post_action_state,
            self._check_artifact_notification,
            self._check_test_notification,
        ]

        # State tracking
        self._paused = False
        self._aborted = False
        self._step_counter = 0

    # ==================================================================
    # Public API — called from DevAgentCore
    # ==================================================================

    async def pre_action(self, action: dict, state) -> bool:
        """Run all pre-action hooks. Returns False to BLOCK the action."""
        for hook in self.pre_action_hooks:
            should_proceed = await hook(action, state)
            if not should_proceed:
                return False
        self._step_counter += 1
        return True

    async def post_action(self, action: dict, result, state):
        """Run all post-action hooks."""
        for hook in self.post_action_hooks:
            await hook(action, result, state)

    async def check_commands(self, state) -> Optional[UserCommand]:
        """Check for pending user commands (non-blocking)."""
        try:
            cmd = self._command_queue.get_nowait()
            await self._handle_command(cmd, state)
            return cmd
        except asyncio.QueueEmpty:
            pass
        return None

    async def wait_for_approval(self, request: ApprovalRequest) -> str:
        """Block until user approves/denies, or timeout."""
        self._pending_approval = request

        # Push to streaming channel so client can render approval UI
        await self.streaming.push_event({
            "type": "approval.requested",
            "data": {
                "id": request.id,
                "type": request.type.value,
                "description": request.description,
                "details": request.details,
                "options": request.options,
                "timeout": request.timeout_seconds,
                "created_at": request.created_at,
            },
            "timestamp": datetime.now().isoformat(),
        })

        # Wait with timeout
        try:
            resolution = await asyncio.wait_for(
                self._wait_resolution(request.id),
                timeout=request.timeout_seconds
            )
        except asyncio.TimeoutError:
            resolution = "auto_deny"

        request.resolved = True
        request.resolution = resolution
        self._pending_approval = None

        await self.streaming.push_event({
            "type": "approval.resolved",
            "data": {"id": request.id, "resolution": resolution},
            "timestamp": datetime.now().isoformat(),
        })

        return resolution

    async def ask_user(self, question: str, options: list[str] = None,
                       context: dict = None) -> str:
        """Agent-initiated question to the user."""
        question_id = f"q_{int(time.time())}"
        await self.streaming.push_event({
            "type": "agent.question",
            "data": {
                "id": question_id,
                "question": question,
                "options": options or [],
                "context": context or {},
            },
            "timestamp": datetime.now().isoformat(),
        })

        try:
            response = await asyncio.wait_for(
                self._wait_resolution(question_id),
                timeout=300  # 5 min for questions
            )
        except asyncio.TimeoutError:
            response = ""

        return response

    def pause(self):
        self._paused = True

    def resume(self):
        self._paused = False

    def abort(self):
        self._aborted = True

    @property
    def is_paused(self) -> bool:
        return self._paused

    @property
    def is_aborted(self) -> bool:
        return self._aborted

    # ==================================================================
    # Command handling — called from SessionManager
    # ==================================================================

    async def enqueue_command(self, cmd: UserCommand):
        """Enqueue a user command from any channel."""
        await self._command_queue.put(cmd)

    async def resolve_approval(self, approval_id: str, resolution: str,
                               user_note: str = ""):
        """Resolve a pending approval from user input."""
        if hasattr(self, f'_future_{approval_id}'):
            future = getattr(self, f'_future_{approval_id}')
            if not future.done():
                future.set_result({"resolution": resolution, "note": user_note})

    # ==================================================================
    # Hook implementations
    # ==================================================================

    async def _check_approval_gate(self, action: dict, state) -> bool:
        """Check if action needs approval before execution."""
        if not self.enable_approval:
            return True

        # Determine approval type
        approval_type = self._classify_action(action, state)
        if approval_type is None:
            return True

        # Check auto-approve policy
        if self.auto_approve_policy.get(approval_type, False):
            return True

        # Build and send approval request
        request = ApprovalRequest(
            id=f"apr_{int(time.time())}",
            type=approval_type,
            description=self._build_approval_description(action, approval_type),
            details={
                "tool": action.get("tool", ""),
                "params_summary": str(action.get("params", {}))[:300],
                "iteration": getattr(state, 'current_iteration', 0),
                "modified_files": getattr(state, 'modified_files', []),
            },
            options=["approve", "deny", "approve_all"],
            timeout_seconds=self._get_timeout(approval_type),
        )

        resolution = await self.wait_for_approval(request)

        if resolution == "approve_all":
            self.auto_approve_policy[approval_type] = True
            return True
        return resolution == "approve"

    async def _publish_pre_action_state(self, action: dict, state):
        """Publish state before action execution."""
        await self.streaming.push_event({
            "type": "agent.decided",
            "task_id": getattr(state, 'task_id', ''),
            "iteration": getattr(state, 'current_iteration', 0),
            "data": {
                "thought": action.get("thought", "")[:300],
                "tool": action.get("tool", ""),
                "params_summary": str(action.get("params", {}))[:200],
            },
            "timestamp": datetime.now().isoformat(),
        })

    async def _publish_post_action_state(self, action: dict, result, state):
        """Publish state after action execution."""
        tool = action.get("tool", "")
        success = getattr(result, 'success', False)

        event_data = {
            "tool": tool,
            "success": success,
            "duration_ms": getattr(result, 'duration_ms', 0) if hasattr(result, 'duration_ms') else 0,
            "output_preview": (getattr(result, 'output', '') or '')[:500],
            "error": (getattr(result, 'error', '') or '')[:300],
        }

        # Enrich with structured data for specific tools
        if tool == "file_edit" and success:
            event_data["diff_preview"] = (getattr(result, 'output', '') or '')[:2000]
            event_data["file"] = action.get("params", {}).get("path", "")
        elif tool == "test_run":
            event_data["test_summary"] = getattr(result, 'structured', {})

        await self.streaming.push_event({
            "type": "tool.completed" if success else "tool.error",
            "task_id": getattr(state, 'task_id', ''),
            "iteration": getattr(state, 'current_iteration', 0),
            "data": event_data,
            "timestamp": datetime.now().isoformat(),
        })

    async def _check_artifact_notification(self, action: dict, result, state):
        """Notify when significant artifacts are created."""
        tool = action.get("tool", "")
        if tool in ("file_write", "file_edit") and getattr(result, 'success', False):
            file_path = action.get("params", {}).get("path", "")
            if file_path:
                await self.streaming.push_event({

                    "task_id": getattr(state, 'task_id', ''),

                        "action": tool,
                        "iteration": getattr(state, 'current_iteration', 0),
                    },
                    "timestamp": datetime.now().isoformat(),
                })

    async def _check_test_notification(self, action: dict, result, state):
        """Notify when test results change significantly."""
        if action.get("tool") == "test_run" and getattr(result, 'success', False):
            structured = getattr(result, 'structured', {})
            failed = structured.get("failed", 0)

            await self.streaming.push_event({
                "type": "test.result",
                "task_id": getattr(state, 'task_id', ''),
                "data": {
                    "passed": structured.get("passed", 0),
                    "failed": failed,
                    "collected": structured.get("collected", 0),
                    "status": "passing" if failed == 0 else "failing",
                },
                "timestamp": datetime.now().isoformat(),
            })

    # ==================================================================
    # Private helpers
    # ==================================================================

    def _classify_action(self, action: dict, state) -> Optional[ApprovalType]:
        """Classify an action to determine if it needs approval."""
        tool = action.get("tool", "")

        # Destructive shell commands
        if tool == "shell_run":
            cmd = action.get("params", {}).get("command", "")
            destructive = [r"rm\s+-rf", r"git\s+push\s+--force",
                          r"git\s+reset\s+--hard", r"sudo\s+",
                          r">\s*/dev/", r"mkfs\.", r"dd\s+if="]
            import re
            for pattern in destructive:
                if re.search(pattern, cmd):
                    return ApprovalType.DESTRUCTIVE_SHELL

        # Large file edits
        if tool == "file_edit":
            old = action.get("params", {}).get("old_string", "")
            if len(old.split("\n")) > 50:
                return ApprovalType.LARGE_EDIT

        return None

    def _build_approval_description(self, action: dict,
                                    atype: ApprovalType) -> str:
        descriptions = {
            ApprovalType.DESTRUCTIVE_SHELL:
                f"Destructive shell command: {action.get('params', {}).get('command', '')[:200]}",
            ApprovalType.LARGE_EDIT:
                f"Large file edit ({len(action.get('params', {}).get('old_string', '').split(chr(10)))} lines) "
                f"in {action.get('params', {}).get('path', '')}",
        }
        return descriptions.get(atype, f"Action requires approval: {action.get('tool', '')}")

    def _get_timeout(self, atype: ApprovalType) -> int:
        timeouts = {
            ApprovalType.DESTRUCTIVE_SHELL: 120,
            ApprovalType.LARGE_EDIT: 60,
            ApprovalType.UNCERTAIN_FIX: 300,
            ApprovalType.UNVERIFIED_EDIT: 60,
        }
        return timeouts.get(atype, 120)

    async def _handle_command(self, cmd: UserCommand, state):
        """Process a user command."""
        if cmd.type == CommandType.PAUSE:
            self.pause()
            await self.streaming.push_event({
                "type": "control.paused",
                "data": {"reason": cmd.data.get("reason", "User requested pause")},
                "timestamp": datetime.now().isoformat(),
            })
        elif cmd.type == CommandType.RESUME:
            self.resume()
        elif cmd.type == CommandType.ABORT:
            self.abort()
            state.status = "ABORTED"
        elif cmd.type == CommandType.REDIRECT:
            # Update task description with new focus
            new_focus = cmd.data.get("focus", "")
            if new_focus and hasattr(state, 'task_description'):
                state.task_description = f"{state.task_description}\n[USER REDIRECT]: {new_focus}"
        elif cmd.type == CommandType.INJECT_CONTEXT:
            context = cmd.data.get("context", "")
            if context and hasattr(state, '_injected_contexts'):
                state._injected_contexts.append({
                    "content": context,
                    "timestamp": datetime.now().isoformat(),
                    "source": "user",
                })

    async def _wait_resolution(self, request_id: str) -> str:
        """Create a future and wait for external resolution."""
        future: asyncio.Future = asyncio.Future()
        setattr(self, f'_future_{request_id}', future)
        try:
            result = await future
            return result.get("resolution", "deny") if isinstance(result, dict) else str(result)
        finally:
            delattr(self, f'_future_{request_id}')
```

### 4.2 SessionManager — 会话管理器

**文件**: `devagent/agentic/session.py`

```python
"""
SessionManager — manages client connections, roles, and message routing.

Supports:
  - Multiple concurrent clients per task
  - Role-based access (controller vs observer)
  - Automatic reconnection with state recovery
  - Message delivery guarantees
"""

import asyncio
import json
import uuid
from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional
from collections import defaultdict


class ClientRole(str, enum.Enum):
    CONTROLLER = "controller"   # Can send commands, approve/deny
    OBSERVER = "observer"       # Read-only, sees events only


@dataclass
class ClientSession:
    """A single connected client."""
    client_id: str
    task_id: str
    role: ClientRole
    transport: str              # "websocket" | "ipc" | "tui"
    connected_at: str
    last_heartbeat: str
    message_queue: asyncio.Queue  # outgoing events for this client

    # Reconnection
    session_token: str          # For reconnecting without re-auth
    last_event_seq: int = 0     # Last event sequence number received
    is_connected: bool = True


class SessionManager:
    """Manages all client sessions across tasks."""

    def __init__(self):
        self._sessions: dict[str, dict[str, ClientSession]] = defaultdict(dict)
        # task_id -> {client_id -> ClientSession}

        self._pending_commands: dict[str, asyncio.Queue] = defaultdict(
            lambda: asyncio.Queue(maxsize=100)
        )
        # task_id -> command queue

        self._event_log: dict[str, list[dict]] = defaultdict(list)
        # task_id -> ordered event list (for replay on reconnect)

        self._task_controllers: dict[str, InteractionController] = {}
        # task_id -> controller instance

    async def register_client(self, task_id: str, role: ClientRole = ClientRole.OBSERVER,
                              transport: str = "websocket",
                              session_token: str = None) -> ClientSession:
        """Register a new client or reconnect an existing one."""
        # Check for reconnection
        if session_token:
            for cid, session in self._sessions.get(task_id, {}).items():
                if session.session_token == session_token:
                    session.is_connected = True
                    session.last_heartbeat = datetime.now().isoformat()
                    # Replay missed events
                    missed = self._event_log[task_id][session.last_event_seq:]
                    for event in missed:
                        await session.message_queue.put(event)
                    session.last_event_seq = len(self._event_log[task_id])
                    return session

        # New client
        client_id = f"client_{uuid.uuid4().hex[:8]}"
        session = ClientSession(
            client_id=client_id,
            task_id=task_id,
            role=role,
            transport=transport,
            connected_at=datetime.now().isoformat(),
            last_heartbeat=datetime.now().isoformat(),
            message_queue=asyncio.Queue(maxsize=200),
            session_token=uuid.uuid4().hex,
        )
        self._sessions[task_id][client_id] = session
        return session

    async def unregister_client(self, task_id: str, client_id: str):
        """Mark client as disconnected (but keep session for reconnection)."""
        if task_id in self._sessions and client_id in self._sessions[task_id]:
            self._sessions[task_id][client_id].is_connected = False

    async def broadcast(self, task_id: str, event: dict):
        """Push event to all connected clients watching a task."""
        # Store for replay
        seq = len(self._event_log[task_id])
        event["_seq"] = seq
        self._event_log[task_id].append(event)

        # Push to all connected clients
        for session in self._sessions.get(task_id, {}).values():
            if session.is_connected:
                try:
                    session.message_queue.put_nowait(event)
                    session.last_event_seq = seq
                except asyncio.QueueFull:
                    pass  # Drop oldest for slow clients

    async def send_command(self, task_id: str, client_id: str,
                           command: UserCommand):
        """Route a user command to the task's InteractionController."""
        controller = self._task_controllers.get(task_id)
        if controller:
            await controller.enqueue_command(command)

    def bind_controller(self, task_id: str, controller: InteractionController):
        """Bind an InteractionController to a task."""
        self._task_controllers[task_id] = controller

    def unbind_controller(self, task_id: str):
        """Remove controller binding after task completion."""
        self._task_controllers.pop(task_id, None)

    def get_connected_count(self, task_id: str) -> int:
        """Count connected clients for a task."""
        return sum(1 for s in self._sessions.get(task_id, {}).values()
                   if s.is_connected)

    async def heartbeat(self, task_id: str, client_id: str):
        """Update heartbeat timestamp."""
        session = self._sessions.get(task_id, {}).get(client_id)
        if session:
            session.last_heartbeat = datetime.now().isoformat()

    async def cleanup_stale(self, max_idle_seconds: int = 300):
        """Remove sessions idle for too long."""
        now = datetime.now()
        for task_id in list(self._sessions.keys()):
            for cid in list(self._sessions[task_id].keys()):
                s = self._sessions[task_id][cid]
                if not s.is_connected:
                    last = datetime.fromisoformat(s.last_heartbeat)
                    if (now - last).total_seconds() > max_idle_seconds:
                        del self._sessions[task_id][cid]
            if not self._sessions[task_id]:
                del self._sessions[task_id]
```

```python
                    continue
                line = line.decode("utf-8")

                    try:
```

### 7.2 API 服务修改 (`api/app.py`)

```python
# 核心变更：添加真正的双向 WebSocket 和审批/指令 API

# === 新增路由 ===

@app.websocket("/api/v2/tasks/{task_id}/interactive")
async def interactive_session(websocket: WebSocket, task_id: str):
    """Bidirectional WebSocket for real-time interaction."""
    await websocket.accept()

    # Get or create session manager (from app state)
    session_mgr = app.state.session_manager

    # Register client
    client = await session_mgr.register_client(
        task_id, role=ClientRole.CONTROLLER, transport="websocket"
    )

    try:
        # Send initial snapshot
        await websocket.send_json({
            "type": "session.created",
            "data": {
                "client_id": client.client_id,
                "session_token": client.session_token,
                "task_id": task_id,
            }
        })

        # Background task: forward events to this client
        async def event_forwarder():
            while client.is_connected:
                try:
                    event = await asyncio.wait_for(
                        client.message_queue.get(), timeout=1.0
                    )
                    await websocket.send_json(event)
                except asyncio.TimeoutError:
                    continue
                except Exception:
                    break

        forwarder_task = asyncio.create_task(event_forwarder())

        # Main loop: receive commands from client
        while True:
            try:
                raw = await asyncio.wait_for(websocket.receive_text(), timeout=30)
            except asyncio.TimeoutError:
                # Send heartbeat
                await websocket.send_json({"type": "heartbeat"})
                continue

            msg = json.loads(raw)
            msg_type = msg.get("type", "")

            if msg_type == "session.heartbeat":
                await session_mgr.heartbeat(task_id, client.client_id)
            elif msg_type == "command.pause":
                await session_mgr.send_command(task_id, client.client_id,
                    UserCommand(type=CommandType.PAUSE))
            elif msg_type == "command.resume":
                await session_mgr.send_command(task_id, client.client_id,
                    UserCommand(type=CommandType.RESUME))
            elif msg_type == "command.abort":
                await session_mgr.send_command(task_id, client.client_id,
                    UserCommand(type=CommandType.ABORT))
            elif msg_type == "command.inject":
                await session_mgr.send_command(task_id, client.client_id,
                    UserCommand(type=CommandType.INJECT_CONTEXT,
                               data={"context": msg.get("data", {}).get("context", "")}))
            elif msg_type == "approval.response":
                controller = session_mgr._task_controllers.get(task_id)
                if controller:
                    await controller.resolve_approval(
                        msg["data"]["approval_id"],
                        msg["data"]["resolution"],
                        msg["data"].get("note", "")
                    )
            elif msg_type == "question.response":
                controller = session_mgr._task_controllers.get(task_id)
                if controller:
                    await controller.resolve_approval(
                        msg["data"]["question_id"],
                        msg["data"]["answer"]
                    )

    except WebSocketDisconnect:
        pass
    finally:
        client.is_connected = False
        await session_mgr.unregister_client(task_id, client.client_id)
        forwarder_task.cancel()
        try:
            await websocket.close()
        except Exception:
            pass


# === 同步 API 审批端点（REST 备选方案） ===

@app.get("/api/v2/tasks/{task_id}/pending-approval")
def get_pending_approval(task_id: str):
    """Get current pending approval for a task."""
    session_mgr = app.state.session_manager
    controller = session_mgr._task_controllers.get(task_id)
    if controller and controller._pending_approval:
        req = controller._pending_approval
        return {
            "has_pending": True,
            "approval": {
                "id": req.id,
                "type": req.type.value,
                "description": req.description,
                "options": req.options,
                "timeout": req.timeout_seconds,
            }
        }
    return {"has_pending": False}


@app.post("/api/v2/tasks/{task_id}/approve")
def approve_action(task_id: str, approval_id: str = "",
                   resolution: str = "approve", note: str = ""):
    """Approve or deny a pending action via REST."""
    session_mgr = app.state.session_manager
    controller = session_mgr._task_controllers.get(task_id)
    if controller:
        # Use asyncio to resolve in the running event loop
        asyncio.ensure_future(
            controller.resolve_approval(approval_id, resolution, note)
        )
        return {"status": "ok", "resolution": resolution}
    return {"status": "error", "message": "Task not found"}, 404


@app.post("/api/v2/tasks/{task_id}/command")
def send_command(task_id: str, command: str = "",
                  data: dict = None):
    """Send a control command via REST API."""
    valid_commands = {"pause", "resume", "abort", "retry", "redirect", "inject"}
    if command not in valid_commands:
        return {"status": "error", "message": f"Invalid command: {command}"}, 400

    session_mgr = app.state.session_manager
    cmd_type = CommandType(command)
    user_cmd = UserCommand(type=cmd_type, data=data or {})
    asyncio.ensure_future(
        session_mgr.send_command(task_id, "api_client", user_cmd)
    )
    return {"status": "ok", "command": command}
```

> **设计原则总结**: 
> 1. Hook机制而非修改循环 — 最小化对核心循环的侵入
> 2. 异步非阻塞 — 交互操作不阻塞 Agent 执行
> 3. 协议统一 — 所有终端共享同一套消息格式
> 4. 状态可恢复 — 基于 checkpoint 支持断线重连
> 5. 渐进交付 — 每阶段可独立部署和测试
