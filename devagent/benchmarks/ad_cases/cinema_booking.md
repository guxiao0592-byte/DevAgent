# 影院订票系统

## 项目描述
开发一个影院在线订票系统，用户可以查看电影场次、选座、订票和支付。

## 功能需求
1. 电影管理：上映电影信息管理（名称、时长、简介、海报）
2. 场次管理：排片管理（放映厅、时间、价格）
3. 座位管理：座位布局设置、选座状态实时更新
4. 订票流程：选择电影→选择场次→选座→确认订单→支付
5. 订单管理：查看历史订单、取消订票（开场前30分钟可取消）
6. 会员系统：积分累计、会员折扣

## 用户角色
- 普通用户：浏览、订票、支付、查看订单
- 影院管理员：管理电影、场次、价格、查看销售报表

## 约束
- 选座后15分钟内未支付自动释放座位
- 每个订单最多购买6张票
- 支持在线支付和会员积分支付
